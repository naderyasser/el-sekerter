# السكرتير الخاص

شات بوت يمسك مواعيد صاحب العمل ويذكّره فيها. تقول له الموعد بكلام عادي
بالعامية السعودية — مكتوب أو بالصوت — وهو يفهمه ويسجّله ويرنّ عليك بوقته.

## الفكرة المعمارية

**المواعيد متخزّنة على الموبايل، والتذكير محلي.** السيرفر دوره الوحيد إنه
يفهم الكلام. يعني:

- التطبيق يشتغل من غير نت — التذكيرات المجدولة على الجهاز بترنّ عادي.
- لو السيرفر وقع، الحاجة الوحيدة اللي بتقف هي فهم رسايل جديدة.
- مفيش قاعدة بيانات على السيرفر أصلًا، ومفيش بيانات مواعيد متخزّنة بره الجهاز.

```
  الموبايل                                    السيرفر
┌──────────────────────────┐              ┌──────────────────────┐
│ SQLite (المواعيد)         │              │ Django + DRF         │
│ الجدولة والإشعارات        │  ── رسالة ──▶ │ /api/secretary/chat  │
│ الشات والصوت              │              │        │             │
│                          │ ◀── أوامر ──  │        ▼             │
│ ينفّذ الأوامر محليًا        │              │  Claude أو DeepSeek  │
└──────────────────────────┘              └──────────────────────┘
```

مع كل رسالة، التطبيق بيبعت مواعيده الحالية ووقت الجهاز. الموديل بيقرا
المواعيد من البرومبت (فمفيش أداة قراءة) وبيستدعي أدوات الكتابة بس. السيرفر
بيحوّل الاستدعاءات لأوامر ويرجّعها؛ التطبيق ينفّذها ويعيد الجدولة.

## الريبو

```
backend/     سيرفر Django — فهم الكلام بس
app/         تطبيق Flutter (أندرويد + آيفون)
```

## تشغيل السيرفر محليًا

```bash
cd backend
pip install -r requirements.txt

cp .env.example .env
# املا .env: SEKERTER_PROVIDER ومفتاح المزوّد و SEKERTER_API_TOKEN
# و DJANGO_SECRET_KEY. ولّد التوكن والمفتاح بـ:
#   python3 -c "import secrets; print(secrets.token_urlsafe(32))"

python3 manage.py runserver
```

مفيش `migrate` ولا `createsuperuser` — مفيش قاعدة بيانات.

### تجربة سريعة

```bash
curl -s http://127.0.0.1:8000/api/secretary/health

curl -s http://127.0.0.1:8000/api/secretary/chat \
  -H "Authorization: Bearer $SEKERTER_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "ذكّرني بموعد الدكتور بكرة الساعة ٥ ونص",
    "now": "2026-08-15T14:30:00+03:00",
    "timezone": "Asia/Riyadh",
    "appointments": [],
    "history": []
  }'
```

الرد:

```json
{
  "reply": "تم، سجّلت موعد الدكتور بكرة الساعة ٥:٣٠ م، وبذكّرك قبلها بساعة.",
  "actions": [
    {
      "type": "create",
      "title": "موعد الدكتور",
      "at": "2026-08-16T17:30:00+03:00",
      "remind_before_minutes": 60,
      "repeat": "none",
      "notes": ""
    }
  ]
}
```

### الاختبارات

```bash
cd backend
python3 manage.py test secretary
```

٣٧ اختبار تغطي المسار كله بمزوّد موك — من غير مفاتيح ومن غير نداءات حقيقية.
منها اختبارات لترجمة كل مزوّد لشكل الـAPI حقّه، وهي أخطر جزء في التبديل بينهم:
نفس المحادثة لازم تتحوّل صح لشكلين مختلفين تمامًا.

## واجهة الـAPI

### `GET /api/secretary/health`
من غير توثيق. بيرجّع `{"status": "ok"}`.

### `POST /api/secretary/chat`
محتاج `Authorization: Bearer <SEKERTER_API_TOKEN>`.

**الطلب**

| الحقل | النوع | الوصف |
|---|---|---|
| `message` | نص | كلام صاحب العمل |
| `now` | نص | وقت الجهاز ISO 8601 بفرق التوقيت — المرجع لأي كلام نسبي |
| `timezone` | نص | `Asia/Riyadh` افتراضيًا |
| `appointments` | قائمة | المواعيد المخزّنة على الجهاز حاليًا |
| `history` | قائمة | آخر رسايل المحادثة (`{role, content}`) |

**الرد**

| الحقل | النوع | الوصف |
|---|---|---|
| `reply` | نص | رد السكرتير اللي يتعرض في الشات |
| `actions` | قائمة | أوامر ينفّذها التطبيق محليًا |

**الأوامر**

| `type` | الحقول |
|---|---|
| `create` | `title`, `at`, `remind_before_minutes`, `repeat`, `notes` |
| `update` | `id` + الحقول اللي هتتغيّر (`null` = سيبه زي ما هو) |
| `delete` | `id` |
| `complete` | `id` |

`repeat` واحدة من: `none`, `daily`, `weekly`, `monthly`, `yearly`.

**الأخطاء**

| الكود | المعنى |
|---|---|
| 400 | طلب ناقص أو شكله غلط |
| 403 | توكن غلط أو ناقص |
| 503 | الموديل مش متاح أو المفتاح مش متظبّط — `detail` فيه رسالة تتعرض للمستخدم |

## المزوّد

السيرفر يشتغل بـClaude أو DeepSeek، والتبديل بمتغيّر واحد في `.env`:

```bash
SEKERTER_PROVIDER=claude     # أو deepseek
```

| | Claude | DeepSeek |
|---|---|---|
| فهم العامية السعودية | أدق | أضعف |
| التواريخ النسبية («الخميس الجاي»، «عقب المغرب») | أدق | يغلط أكثر |
| التكلفة | أعلى | أرخص بكثير |
| تكاش البرومبت | مدعوم | غير مدعوم |

المنطق كله محايد تجاه المزوّد: `brain.py` فيه حلقة الأدوات والتحقق، وكل مزوّد
في `secretary/providers/` يترجم بس بين الشكل المحايد وشكل الـAPI حقّه. إضافة
مزوّد ثالث = ملف واحد جديد.

## أمان

- المفاتيح في `backend/.env` بس، والملف ده في `.gitignore`.
- التوثيق بتوكن ثابت واحد (مستخدم واحد) — المقارنة ثابتة الزمن في
  `secretary/auth.py`، وهي نقطة التغيير الوحيدة لو المشروع اتوسّع لأكتر
  من مستخدم.
- السيرفر مبيخزّنش أي ميعاد ولا رسالة.
- شغّل السيرفر خلف HTTPS في الإنتاج — التوكن بيتبعت في الهيدر.
